# MASNA3 (مَصنع)
منصة عربية تحوّل فكرتك إلى خطة تنفيذ + مشروع ويب حقيقي (HTML/CSS/JS) قابل للتنزيل كملف ZIP.

## التشغيل
افتح `index.html` في أي متصفح حديث. لا يلزم تثبيت أو إنترنت أو API مدفوع. (اختياري: `python -m http.server`)

## الاستخدام
1. اكتب فكرتك واضغط «حلّل الفكرة» (أو ابدأ من قالب).
2. راجع الخطة، عدّل الملفات من تبويب «الملفات»، وعاين من «المعاينة».
3. نزّل ZIP. المشاريع تُحفظ في localStorage ويمكن فتحها وحذفها من «مشاريعي».

## الاختبار
`node tests/test.js` (يحتاج Node.js وPython3 للتحقق من ZIP).

## البنية والتوسع
- `js/analyzer.js`: سجل الأنواع `TYPES` وتحليل الفكرة بالكلمات المفتاحية (بدون ذكاء اصطناعي).
- `js/generator.js`: مولّد الملفات لكل نوع. لإضافة ألعاب/أندرويد/ذكاء اصطناعي: أضف نوعًا في `TYPES` ومولّدًا في `G`.
- `js/zip.js`: كاتب ZIP ذاتي بلا مكتبات. `js/storage.js`: الحفظ المحلي. `js/app.js`: الواجهة.

## الحدود الحالية
التحليل قائم على كلمات مفتاحية وليس فهمًا حقيقيًا للغة؛ القوالب أساسية؛ ZIP بدون ضغط؛ لا إرسال بيانات لأي خدمة خارجية.
